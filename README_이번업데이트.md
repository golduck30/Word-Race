# Word-Race · 상점/미리보기 + 펫 날개 + 혼자하기 통합 수정

이 ZIP은 현재 Word-Race 저장소에 덮어쓰는 업데이트입니다. **기존 _todayword_source 와 firebase-config.js 를 삭제하거나 교체하지 마세요.**

## 변경 사항
- 펫 날개를 좌우 균형 맞춰 펫 몸 뒤쪽으로 축소 배치 (기존 SVG 7종 사용)
- 혼자하기 타일/한글 키보드 배색·크기·간격을 대결 화면에 맞춤
- 혼자하기 정답 성공 시 연습 점수 +20점, **코인 지급 0**, 새 문제에서도 점수 누적 (브라우저 새로고침하면 초기화)
- 대결 모드 정답 성공 시 점수 100점 고정 (**원본의 정답 시도 횟수·속도·시간·힌트에 따른 가변 점수 계산은 대체**). 출제자 보너스 규칙은 원본 유지
- nonemo 상점 카테고리 아이템 목록 제공. 아이템 클릭은 **미리보기만**; 별도 버튼을 눌러 구매/장착
- 펫 상점도 아이템 클릭 후 미리보기 → 구매/장착
- 기존 닉네임 보관함·코인·펫 마이그레이션 모듈 보존

## 설치
1. GitHub Desktop에서 Fetch/Pull origin으로 최신 상태를 받습니다.
2. ZIP **내부** 파일/폴더를 Word-Race 로컬 저장소 루트에 덮어씁니다.
3. 현재 Firebase 설정이 들어 있는 `firebase-config.js`를 유지합니다. ` _todayword_source` 폴더도 유지합니다.
4. Commit to main → Push origin
5. Actions 배포가 초록색인지 확인한 다음 강력 새로고침합니다.

## 참고
- 최근 공개 Word-Race 저장소에는 구형 드레스룸 코드가 남아 있는 것이 확인됐습니다. 이 ZIP의 `addons/word-race.js`와 `assets/nonemo/catalog.json`을 함께 업로드하세요.
- 일부 원본 캐릭터 부품은 조립용 부위이므로 상점 아이템 수와 PNG 전체 파일 수가 같지 않습니다.
- 실제 Firebase 멀티유저 테스트와 라이브 브라우저 구매 동작은 배포 후 검증이 필요합니다.
- 100점/20점은 게임 점수이며 코인이 아닙니다.
