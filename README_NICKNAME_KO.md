# Word-Race 동일 닉네임 아이템 유지 패치

이 패치는 Firebase 익명 인증 UID 대신 **닉네임을 보관함 식별자로** 사용하도록 바꿉니다.

- 같은 닉네임으로 재접속하면 **코인, nonemo 의상/헤어/표정 구매 내역 및 장착, 펫 및 날개 구매·장착**을 함께 이어서 사용합니다.
- 다른 PC나 스마트폰, 브라우저에서 접속해도 동일한 닉네임이면 같은 보관함을 사용합니다.
- 기존 Firebase `wrEconomy/state/users/<UID>`에 저장된 내역은 최초 닉네임 연결 시 해당 닉네임 보관함으로 옮겨집니다. 다른 기기에 같은 닉네임 보관함이 이미 있으면 그쪽의 코인 잔액이 기준이 되며, 이전 기기에서 구매한 아이템은 합칩니다.
- **todayword에서 Word-Race로 옮기는 기능과는 별개입니다.** 처음 한 번 todayword 아이템 가져오기는 기존 안내대로 진행해야 합니다.
- 이름의 띄어쓰기 앞뒤는 제거하고, 영문 대소문자는 구분하지 않습니다. 서로 다른 이름을 쓰면 서로 다른 보관함입니다.
- 같은 닉네임을 다른 사람이 입력하면 똑같은 보관함을 함께 사용하게 됩니다. 비밀번호는 없으며 지인끼리 신뢰하고 사용하는 방식입니다.
- 현재의 Firebase 보안 규칙에서는 인증된 사용자가 경제 상태를 수정할 수 있으므로 악의적인 조작을 막을 수 없습니다. **현금·유료코인용으로 쓰면 안 됩니다.**

## 설치

1. 이 ZIP의 `addons/spark-economy.js`, `addons/word-race.js` 파일을 GitHub Desktop의 `Word-Race/addons/` 폴더에 **덮어씁니다**.
2. GitHub Desktop에서 `Commit to main` → `Push origin`을 누릅니다.
3. GitHub Actions의 `Deploy independent Word-Race`가 성공했는지 확인합니다.
4. 기존과 같은 닉네임으로 플레이하고, 드레스룸/펫 꾸미기에서 구매 아이템과 코인을 확인합니다. 페이지 접속 후 닉네임이 입력되면 몇 초 안에 동기화됩니다.
5. **Firebase 규칙은 변경하지 않아도 됩니다.** 기존 `wrEconomy/state` 경로를 그대로 사용합니다.

## 적용 범위

경제 보관함만 닉네임 기반으로 변경합니다. 게임 참여자 구분과 관전자 예측의 라운드별 중복 참가 제한은 여전히 Firebase 익명 UID를 사용하므로 **기기를 바꿔서 같은 판에 중복 베팅하는 행위**는 완전히 막지 못합니다. 또한 기존 게임의 로컬 닉네임이 빈 상태면 우선 익명 UID 보관함으로 작동하다가, 닉네임이 정해진 시점에 닉네임 보관함에 연결됩니다.
