# Word-Race 8자모 힌트 + nonemo 추가 표정 업데이트

## 변경 사항
- 8자모 대결 라운드: 힌트 최대 3회
- 5·6·7자모 대결 라운드: 힌트 최대 2회(기존 유지)
- 혼자하기: 힌트 없음(기존 유지)
- nonemo 원본 ZIP에 있으나 상점에 독립적으로 노출되지 않던 눈 10종과 입 6종 조합 → **표정 60종 추가**. 기존 표정 15종 유지, 총 75종.
- 피부 3, 의상 28, 헤어 45, 하의 3, 안경 5, 수염 28 등의 기존 아이템 그대로 유지.

## 실제 원본 ZIP과 항목 수 차이
원본 PNG 파일 180개는 판매 아이템 180개가 아닙니다. 몸통·팔다리·소매·머리 앞/뒤 파츠가 포함됩니다. 새 표정은 원본의 눈/입 파츠를 재조합해 제작했고, 다른 새 외부 에셋은 추가하지 않았습니다.

## 적용
1. GitHub Desktop에서 `Fetch origin` / 필요 시 `Pull origin`을 먼저 실행.
2. ZIP 내부 `tools`, `assets`, `tests` 폴더를 Word-Race 저장소 **최상위 폴더**에 그대로 복사하고 기존 `tools/build.py`, `assets/nonemo/catalog.json` 덮어쓰기.
3. **기존 `firebase-config.js`, `_todayword_source` 및 다른 addons 파일은 절대 삭제하지 않기.**
4. Commit → Push origin. GitHub Actions 최신 Deploy에서 성공 확인. 새로고침(Ctrl+F5).
5. 8자모 라운드에서 힌트 요청 3회인지, 드레스룸 `표정`에 기존 15개 + 신규 60개가 표시되는지 확인.

## 주의
- 현재 GitHub에 저장된 원본 엔진 `game.js`가 기존의 `MAX_HINTS_PER_ROUND = 2` 구조를 유지할 때 동작합니다. 다른 버전이면 빌드에서 안전하게 중단합니다.
- ZIP은 **업데이트 패치**이며 완전한 독립 게임 백업 파일은 아닙니다.
- 새 표정 60개는 모두 nonemo가 제공한 CC0 눈/입 파츠를 조합했습니다.
- 표정은 기존 코인 상점 규칙에 따라 **90코인**으로 정했습니다(기획상 신규 가격, 원작이 책정한 금액 아님).
- 온라인 Firebase 실제 사용자의 동시 3회 힌트 투표 기능까지는 이 환경에서 테스트하지 못했습니다.
