# Word-Race — 앞머리 경계 및 todayword 전체 이전

- 앞머리와 뒷머리가 겹치는 윗부분의 미세한 경계가 보이지 않도록 **뒷머리 레이어의 상단만 부드럽게 가리는 방식**으로 수정했습니다. 원본 nonemo PNG는 변경하지 않았습니다. 일부 머리 조합에서는 경계가 남을 수 있으므로 배포 후 확인해 주세요.
- `todayword 아이템·코인 전체 가져오기`를 누르면 이전 미리보기(코인/펫·날개/보상)를 확인 후 지급합니다.
- 기존 todayword 코인은 **전액 합산 지급**, 구입했지만 Word-Race에 직접 호환되지 않는 `owned` 아이템은 **1개당 10코인**을 지급합니다.
- 다른 디바이스에만 저장된 todayword 기록은 직접 읽을 수 없습니다. 기존 todayword를 사용하던 **같은 브라우저**에서 이전해야 합니다.
- 같은 Word-Race 닉네임으로 이어서 사용하며 **전체 이전은 닉네임 보관함 기준 1회**입니다. 예전에 펫만 옮긴 사용자는 전체 이전을 따로 진행할 수 있습니다.
- 별도 서버가 없는 Firebase Spark 구조이므로 닉네임/브라우저 기록은 신뢰 기반입니다. 사용자의 브라우저 저장 정보가 과거 서버 기록보다 오래됐을 수 있으므로, 원본 사이트에서 먼저 닉네임의 최신 코인과 보유 목록을 확인해 주세요.
- Word-Race Firebase 설정 파일, `_todayword_source`는 이 패키지에 포함하지 않았으며 기존 파일을 유지해야 합니다.
