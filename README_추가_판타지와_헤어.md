# Word-Race — 앞머리·뒷머리 + nonemo 판타지 업데이트

## 변경
- 앞머리 45종을 별도 탭에서 구매/장착할 수 있습니다.
- 뒷머리 27종과 미착용 1종을 새 탭에서 구매/장착할 수 있습니다.
- 기존 `hair` 아이템의 구매 기록은 같은 ID의 앞머리 구매 기록으로 인정합니다. 재구매할 필요 없습니다.
- 원본의 눈 10종 × 입 6종 = 추가 표정 60종, 기존 표정 15종을 보존합니다.
- 별첨 판타지팩의 10종(요정·유령·기사·드워프·오우거·해골·뱀파이어·마녀·마법사·좀비)을 `판타지 변신` 탭에 추가합니다. 변신 스킨은 전신 한 벌로 표시하며 기본 헤어·의상을 자동으로 숨깁니다. 해제하면 기존 코디가 다시 나옵니다.
- 코인은 이름별 기존 보관함을 사용합니다. 신규 카테고리를 넣어도 기존 구매·펫 기록은 그대로 유지합니다.
- 8자모 힌트 최대 3회 / 5~7자모 최대 2회 빌드 규칙 포함.
- 최근 UI 수정(혼자하기 화면 키보드, 펫 날개 양쪽 표시, 오늘의 단어 헤더 위 배치)을 합쳤습니다.

## 적용
1. GitHub Desktop에서 최신 원격 커밋을 Pull 합니다.
2. ZIP의 **내부 파일들**을 Word-Race 프로젝트 최상위 폴더에 복사합니다. 같은 이름은 덮어씁니다.
3. `firebase-config.js`와 `_todayword_source`를 삭제하거나 교체하지 않습니다. 이 배포 ZIP에는 두 항목이 없습니다.
4. Commit → Push 하고 GitHub Actions 최신 배포가 성공했는지 확인합니다.
5. 드레스룸의 앞머리/뒷머리/판타지 변신 탭에서 실제 구매/장착을 확인합니다.

## 제작·라이선스
- 기본 캐릭터: nonemo Free Character Creation Asset Pack — CC0.
- 판타지: 사용자가 올린 nonemo Fantasy Creatures Asset Pack — CC0.
- 판타지 원본 파츠는 `assets/nonemo/fantasy_parts`에 보관했고, 게임용 전신 PNG는 각 파츠를 조합해 제작했습니다.
- 새 판타지 스킨은 일반 인간형 파츠의 옷과 개별 호환을 의미하지 않습니다. 기존 캐릭터 위에 판타지 모자를 그대로 올리는 것은 별도 좌표 작업이 필요합니다.
- Spark 무료 버전의 브라우저 경제 데이터는 악의적 클라이언트 조작을 완전히 방지할 수 없습니다.

## 검증 범위
- 파일/카탈로그 일치, 10종 판타지 PNG, 27종 뒷머리 이미지, JS 문법 및 로컬 경제 로직 검사.
- 실제 GitHub Pages + Firebase 다중 사용자 장착 동기화는 미검증입니다.
